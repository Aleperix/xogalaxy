# XO Galaxy v23.1

## Nuevos
- **Estilos de nick**: sistema tipo Minecraft (§). Colores (`§0`–`§9`, `§a`–`§f`), negrita (`§l`), itálica (`§o`), subrayado (`§n`), tachado (`§m`), reset (`§r`). Hay una paleta de botones en el nick para insertarlos fácil; longitud máxima ampliada a 64.
- **Tooltip en menciones**: al pasar el mouse sobre @nombre resuelve el perfil vía `/users/suggest` y muestra nombre completo, avatar y badge-check; click abre el perfil si existe coincidencia exacta.

## Corregido
- La barra de sugerencias del chat siempre se veía (override de CSS sobre `[hidden]`); ahora se oculta correctamente y no reaparece al completar una mención.
- El icono de verificado ahora usa **badge-check** (lucide) en color primario (máscara CSS) en vez del viejo ✓.

## Técnico
- Nuevo módulo `nick-style.js` (compartido: chat, archivo del chat, sugerencias, tests).
- Límite server NICK_MAX ampliado de 32→64 para nicknames decorados.
