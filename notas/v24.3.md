## v24.3 — Toolbar markdown + fixes de UI

### Toolbar de formato en el input
- Barra de botones: **B** (negrita), *I* (itálica), <u>U</u> (subrayado), ~~S~~ (tachado).
- Envuelve el texto seleccionado con sintaxis Markdown (`**`, `*`, `__`, `~~`).
- Los estilos se renderizan en el chat al enviar el mensaje (vía `marked` + DOMPurify).

### Input full-width
- El input de mensaje ahora ocupa todo el ancho disponible entre el nick y el botón Enviar.
- Layout: `[Nick] [============ Input + Toolbar ============] [Enviar]`.

### Alineación nombre/avatar
- Nombre y hora ahora arrancan al top del avatar (`align-self: flex-start` en `.chat-msg-main`).
