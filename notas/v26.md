v26 — Editor enriquecido (Tiptap), imágenes en R2 y menciones en posts

## Editor enriquecido

- **Tiptap WYSIWYG**: el tool de aportes ahora usa un editor enriquecido (negrita, cursiva, subrayado, tachado, títulos, listas, citas, bloques de código, líneas, deshacer/rehacer) en vez del textarea plano.
- **Preview inline**: al editar ves el formato final directamente en la caja, sin toggle de vista previa.
- **Contador de caracteres** en vivo con aviso (naranja >90%, rojo al límite).
- **Carga diferida**: el editor se descarga solo cuando abrís el tool (~139KB gzip on-demand), el resto del blog mantiene la misma velocidad.

## Imágenes con R2

- **Subida de imágenes** dentro del editor: arrastrá o pegá una imagen y se sube a R2 automáticamente.
- **Solo cuentas Google** pueden subir (visitantes anónimos no).
- **Límites**: formatos JPEG/PNG/WebP/GIF, máx 5MB, redimensionadas a WebP máx 1600px.
- **Deduplicación**: mismo archivo ya subido = no se re-guarda.
- El bucket `xogalaxy-images` debe habilitarse en Cloudflare Dashboard antes de usar el upload.

## Menciones en posts

- **@menciones** dentro del editor con autocompletado de usuarios Google (mismas reglas que el chat).
- **Notificaciones**: si mencionás a alguien, recibe notificación tipo `mention_post`.
- **Resaltado**: en el blog, los posts leídos muestran las menciones resaltadas igual que en el chat.

## Técnico

- Nuevo módulo `web/src/editor.js` (Tiptap + turndown). El HTML del editor se convierte a Markdown para guardar (storage sigue siendo Markdown).
- Nuevo `web/build-tiptap.mjs` (esbuild) genera `dist/tiptap.js`, servido por el worker en `/dist/tiptap.js` (KV, con CORS y cache).
- Nuevo endpoint worker `POST /images/upload` (`worker/src/images.js`) con SHA-256 real, resize WebP y dedupe.
- El template inyecta `window.XOGALAXY_CONFIG.tiptap` con la URL del bundle.
- Test: 153 web + 159 worker, incluye round-trip de markdown, upload de imagen (errores y éxito), y resaltado de menciones.
