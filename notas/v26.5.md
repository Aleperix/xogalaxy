v26.5 — Toolbar de editor pulido: iconos, enlaces y texto enriquecido

## Editorial

- El tool de aportes ahora habla de **texto enriquecido** (negrita, títulos, listas, citas, código, imágenes y enlaces) en vez de "Markdown".

## Toolbar con iconos

- Los botones ahora usan iconos lucide en vez de letras sueltas (B/I/U/S) y emoji.
- **Imagen**: botón con icono de imagen (antes era un 📎 confuso).

## Botón de Enlace

- Nuevo botón **Enlace** para agregar links con URL y título (tooltip) a texto seleccionado.
- También permite **enlazar imágenes**: seleccioná la imagen y app likala con URL + título; se guarda como `[![alt](src)](href)`.
- Se puede quitar un enlace dejando la URL vacía.

## Fix: botones H2/H3

- Antes, al poner un H2 o H3 se activaban **ambos** botones a la vez.
- Ahora el estado activo es por nivel (`heading, level:2` vs `level:3`): solo el que corresponde se resalta.

## Técnico

- `Image` pasa a `inline: true` para poder envolver imágenes en un enlace.
- Turndown serializa enlaces con título y enlaces a imágenes correctamente.
- Tests: 158 web (round-trip markdown de enlace/imagen, active por nivel, intro).
