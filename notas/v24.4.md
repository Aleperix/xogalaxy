## v24.4 — Paleta de estilos para mensajes del chat

### Paleta de estilos "A"
- Botón "A" a la izquierda del input que abre un popup con formatos y colores.
- Formatos: **B** negrita, *I* itálica, <u>U</u> subrayado, ~~S~~ tachado, ⭯ Reset.
- Colores: 16 swatches de colores (§0-§f).
- La opción activa se resalta con borde.

### Contenteditable con preview híbrido
- El input de mensaje ahora es un `contenteditable` que muestra el texto formateado en tiempo real.
- La sintaxis markdown se muestra con baja opacidad (`opacity: 0.35`) junto al texto formateado.
- Al escribir se ve inmediatamente el resultado (negrita, itálica, color, etc.).

### Persistencia en memoria
- El estilo activo (color/formato) se mantiene entre mensajes.
- Se limpia al enviar o al hacer reset.
- No se persiste en localStorage — al recargar vuelve al estado inicial.

### Renderizado del mensaje enviado
- El body del mensaje se renderiza con `msgStyle.renderMsg()` que usa clases CSS.
- Colores: `msg-c0` a `msg-cf`. Formatos: `msg-bold`, `msg-italic`, `msg-underline`, `msg-strike`.

### Fix alineación
- `.chat-msg-head` ahora usa `align-items: start` en vez de `baseline`.
- Nombre y hora arrancan al top del avatar.

### Input full-width
- Layout: `[Nick] [A] [input] [Enviar]` — el input ocupa todo el ancho disponible.
