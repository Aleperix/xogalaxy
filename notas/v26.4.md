v26.4 — imágenes en el editor (WYSIWYG real), worker media y bucket R2

## Imágenes dentro del editor

- **Fix: la imagen ahora se inserta como `<img>` real en el editor** (antes aparecía el código markdown `![](...)` en texto plano).
- Al arrastrar o pegar una imagen se muestra la previsualización local al instante y se reemplaza por la URL remota de R2 al terminar la subida (placeholder `Subiendo…` con estado).
- Preview redimensionado a WebP en el navegador (workerd no tiene canvas), deduplicación por hash, preservando el storage en Markdown.

## Worker de media dedicado

- Nuevo subdominio `media.xogalaxy.workers.dev` que sirve las imágenes de R2 con `correct-content-type`.
- Keys planas `images/<hash>.<ext>` en el bucket `xogalaxy-media` (renombrado desde `xogalaxy-images`).
- El backend devuelve URLs de media y el blog muestra las imágenes sin cortar.

## Limpieza

- Se eliminó `img.xogalaxy.workers.dev`, un worker viejo de 2024 sin uso (proxy a imgur).

## Técnico

- `web/build.mjs` ahora también genera `dist/tiptap.js` (build de un solo paso).
- `docker-do` del editor: `setImage` + transcripción `htmlToMarkdown` con test de round-trip.
- Render del blog sanitizado (DOMPurify): las imágenes se muestran como `<img>` con URL de media.
- Tests: 155 web.
