v25.1 — Fix autor en Blogger + perfil clickeable

## Fix

- **Autor en Blogger**: el script inline del template ahora procesa cada `article.post` individualmente (antes solo tomaba el primer `.xo-author-data`). Avatar + nombre se muestran por post.
- **Nombre y avatar clickeables**: tanto en el template de Blogger como en las post cards del frontend, el nombre y avatar del autor son clickeables y abren el perfil (`showProfile()`).
- **data-sub en byline**: `publishToBlogger` ahora inyecta `data-sub` y `data-visitor` además de `data-name` y `data-pic`, para que el perfil se pueda abrir correctamente.
- **Migración mejorada**: el script de migración re-procesa posts existentes (sin data-sub) y usa la foto real del owner desde D1.

## Técnico

- Template CSS: `.post-author` ahora es `display:inline-flex` con gap; avatar usa `.post-author-avatar` con `border-radius:50%`. `.xo-custom-author` y `.pt-post-author-name` tienen hover underline + color signal.
- Template script: loop `article.post` con `querySelector('.xo-author-data')` por artículo. Click handler llama `XOGalaxy.posts.showProfile()` si está disponible, con `role="link"` y `tabindex="0"` para accesibilidad.
- Worker `publishToBlogger`: byline incluye `data-sub` y `data-visitor` del post.author.
- Frontend `postCard()`: avatar tiene `addEventListener("click")` para abrir perfil, igual que el nombre.
- Migración: usa `AUTHOR_SUB = "107284810985445490995"` y `AUTHOR_PIC` real de D1 profiles.
