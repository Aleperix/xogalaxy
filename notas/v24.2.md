## v24.2 — Markdown en chat + avatares CSS

### Markdown en el chat
- Eliminado el sistema de estilos § (Minecraft) del chat.
- Los mensajes ahora usan Markdown estándar (negrita, itálica, código, listas, etc.).
- `marked` + DOMPurify renderizan el contenido en tiempo real al enviarse.
- El nombre del usuario se muestra como texto plano (sin códigos de estilo).

### Avatar CSS para invitados y usuarios sin foto
- Invitados (sin cuenta): avatar circular con signo de interrogación.
- Usuarios verificados sin foto de perfil: avatar circular con icono de persona (Lucide SVG).
- Cuentas con foto de perfil: mantienen la imagen normal.

### Limpieza
- Eliminado `nick-style.js` y toda la paleta de colores/formateo del chat.
- Eliminada toda la paleta de estilos del CSS del template.
- Botón de formato eliminado del input de mensaje.
